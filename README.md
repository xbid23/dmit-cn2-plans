## DMIT 的 CN2 到底指哪条线路

DMIT 的套餐名是一套固定格式：机房.线路档位.规格。三个机房（洛杉矶 LAX、香港 HKG、东京 TYO）各有一条产品线，线路分三档，同一档位在不同机房的价格和流量差别很大。

| 档位 | 线路 | 适合谁 |
| --- | --- | --- |
| Premium（Pro） | 三网 CN2 GIA，电信走 AS4809 | 电信宽带用户；晚高峰不能掉速的业务 |
| Eyeball（EB） | 移动 CMIN2 方向优化 | 联通、移动用户；每月流量吃紧 |
| Tier 1（T1） | 国际线路，中国大陆走普通线路 | 海外用户站点、API、CDN 边缘、落地机 |

CN2 GIA 是中国电信的国际精品网，特点是晚高峰不绕路、丢包低。DMIT 早年洛杉矶只做到去程电信联通走 CN2 GIA、回程电信走 CN2 GIA，后来才补成三网，现在买到的 Pro 按三网 CN2 GIA 算。这条线路也是 DMIT 价格比同类贵出不少的主要原因。

延迟方面，第三方测评给的数据是洛杉矶三网 150–180ms、丢包很低，香港节点国内平均 39ms 左右、基本不丢包。洛杉矶这个数字对美西机房属于正常偏好的水平，香港的数字才是它敢卖四倍价的底气。

## 下单前必须知道的限制

**只提供 Linux 系统**，没有 Windows。要跑 Windows 环境得另找商家。

**强制 SSH 密钥登录**，不支持 root 密码登录。首次购买后要在后台下载密钥文件，再用 SSH 客户端连。这一步对新手是实打实的门槛，买完连不上多半是漏了这一步。

**IP 被墙可以换，但有条件**。每 15 天一次免费更换，其他情况 $5 一次。这条对需要长期稳定 IP 的业务很关键。

**退款窗口**。据第三方整理的说法，3 天内可无理由全额退款，30 天内按剩余价值退款，可退到账户余额，也可退回原支付方式（会扣支付手续费）。这条只有单一来源，下单前值得在结算页再确认一次条款。

**非 Pro 系列可能切路由**。EB 和 T1 在遇到攻击或成本压力时，路由可能被调整。CN2 GIA 是硬需求的话，直接买 Pro，别指望 EB 长期稳定走同一条路。

**硬件维护不一定提前发邮件**。这一条被不少用户吐槽过，跑高可用业务要自己有容灾方案。

**超额处理规则按机房不同**。洛杉矶 Pro 和 EB 超过月流量后限速继续跑，不停机、不产生额外账单；香港和东京的 Pro、EB 按第三方整理的套餐表是超量暂停。下单前在购物车页面确认一遍当前规则。

**流媒体解锁不保证**。有测评说原生 IP 实测能开 Netflix、TikTok，也有测评说 Netflix 和 Disney+ 不保证 100%。以下单时客服确认的当前 IP 段为准，别把解锁当成购买理由。

**热门套餐经常缺货**。DMIT 严格控制单台母机的用户数，代价是入门款和活动款补货慢。
